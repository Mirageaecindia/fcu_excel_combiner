DM_extrator

Merge the FCU schedule, people report and vendor report into the Summary of Thermal Load Calculation workbook. Everything runs in your browser; no file is uploaded.

Prerequisites

  • FCU schedule: the FCU Tag column must be filled on the first row of every unit. A row with an empty FCU Tag is treated as a sub part of the tag above it: its area and air flow are added to that unit (e.g. FCU-03 with sub rows 124 + 11 L/s becomes one unit with 135 L/s). The Units Reference column is the FCU Tag.
  • No. of People: upload the HAP Space Input Data PDF(s). The Occupancy value under each space (2.4 People) is used. Without a PDF you can enter a default value or leave the column empty.
  • Outdoor Air is always left empty.
